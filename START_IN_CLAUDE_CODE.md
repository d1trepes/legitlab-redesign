# Скопируй этот промпт в Claude Code

Открой репозиторий `d1trepes/legitlab-redesign` в Claude Code и отправь **один запрос** ниже. Документы в репозитории уже служат контекстом.

---

Создай полноценную, визуально цельную демоверсию сайта Legit Lab **в коде**, непосредственно в этом репозитории.

Сначала прочитай `CLAUDE.md`, затем `docs/CLAUDE_BUILD_SPEC.md`, `docs/ASSET_REGISTER.md`, `docs/REFERENCE_TO_SECTIONS.md`, `docs/QUALITY_GATE.md` и актуальные решения в `docs/DECISIONS.md`. Остальные файлы `docs/` используй как детали. Не начинай новый цикл интервью, аудита и генерации логотипа: нужные решения, графический знак и изображения худи уже хранятся здесь.

Сделай **весь сайт-демо**, не один hero: мощная главная на 1440, качественный адаптив 390, две монохромные темы, рабочая навигация, все восемь обязательных секций, осмысленный браузерный демо-сценарий «Начать проверку» и страницу демонстрационного формата результата. Обязательные акценты: огромная надпись LEGIT LAB за настоящим худи, выбранный знак C2 Compact, fashion-editorial арт-дирекшн, читабельный H1 и CTA, «Примеры проверок» с перекрытием нижнего края hero, ясная ценность услуги перед оплатой. Никакого cyber/AI/glow и случайных карточек.

Используй только существующие брендовые изображения/знак из `assets/`; не перерисовывай их. У репозитория нет проверенных публичных кейсов, реальных цен, утвержденных платёжных методов и лицензированных TT-шрифтов — **не изобретай их**. Там, где контента не хватает, реализуй эстетичные, явно маркированные демонстрационные структуры, без ложных вердиктов, отзывов или сертификатов. Не подключай production/API/реальную оплату.

Если кода нет — создай Next.js + TypeScript проект. Решай обратимые детали самостоятельно, не задавай мне вопросы по каждому отступу. Запусти доступные проверки, исправь ошибки, покажи ссылку на preview если есть возможность, сообщи команды запуска и что ещё не подтверждено. Подготовь аккуратные изменения для коммита/PR. **Не публикуй в production без моего разрешения.**

---

Ожидаемый первый результат: **рабочий сайт, который можно открыть и оценить глазами**, а не очередной документ с вопросами.
