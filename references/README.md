# Референсы

Брать композицию, приёмы и уровень. Не копировать пиксель в пиксель, не переносить чужие тексты и бренды.

## Как добавлять новый референс

Файл кладётся в эту папку под следующим номером: `R8-<коротко-о-чём>.png`, `R9-…` и так далее. В таблицу ниже добавляется строка: что в референсе нравится и где это использовать. Без подписи референс не добавляем — следующий чат должен понимать, зачем он здесь.

## Отклонённая версия — `failed-v2/`

Прошлая версия главной, которую владелец отклонил. В имени файла оценка:
GOOD — оставить идею и развивать, OK — терпимо, BAD — не повторять, REMOVE — блок убрать. Подробный разбор — в `BRIEF.md`.
