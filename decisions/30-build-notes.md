# Итог чата 3 — сборка главной (десктоп)

Главная собрана и опубликована: https://d1trepes.github.io/legitlab-redesign/ — код в `site/`. Владелец принял («всё классно»). Мобильной версии нет — она в чате 4 (`chats/4-mobile.md`).

## Что сделано

- `site/index.html`, `site/styles.css`, `site/main.js` — строго по `25-prototype.html` и `25-build-prompt.md`: шапка, 6 блоков (первый экран, Что мы проверяем, Как это работает, Настоящие проверки, Статьи, Финальный призыв), футер. Без сборщиков.
- Резиновая сетка, поля 48 px; проверено на 1024, 1440, 1920 — без горизонтальной прокрутки.
- Данные: `content/catalog.json` (16 ID и пропорции — `22-photos.md`, в коде есть запасная копия), `articles.json` (ссылки, бренд, описание), `links.json` (Telegram, TikTok) — подгружаются по raw-ссылкам.
- Внутренние страницы — окно «Страница в разработке» (белый лист, 22 px 600, «Эта страница появится позже», «Закрыть»; Esc, клик вне окна). Telegram, TikTok, статьи — настоящие ссылки в новой вкладке.
- Reduced motion — только системная настройка (служебная панель прототипа не перенесена). Без JS видны заголовок, текст и кнопки первого экрана, куртка по центру.
- Самопроверка по запретам брифа пройдена.
