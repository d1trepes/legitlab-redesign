# DECISIONS — журнал согласованных решений
Обновлено: 2026-11-07.

## [РЕШЕНИЕ]
- D-001: Название Legit Lab и домен legit-lab.com сохраняем.
- D-002: На первом этапе только B2C; B2B и партнёрские программы исключены.
- D-003: Без Figma; ChatGPT = штаб, Codex = работа в коде, GitHub = общие спецификации и контроль версий.
- D-004: Сначала полный UX-аудит, затем референсы и айдентика, только потом разработка.
- D-005: Главная: header → hero → real checks → how we check → pricing → SEO/articles → final CTA → footer.
- D-006: Пользователь лично утверждает выбранную айдентику, логотип и направление дизайна; сохраняем альтернативы.
- D-007: Этот репозиторий только для отдельной демоверсии; действующий сайт не изменяем.

- D-008 (07.11.2026, инициатор): **Принцип локализации стоимости для B2C** — пользователь должен иметь возможность выбрать свою страну и увидеть понятную цену в соответствующей валюте. Для Беларуси — BYN; для будущего выхода в Россию — RUB; для прочих стран — валюта только если этот рынок и способ оплаты реально поддерживаются. Причина: USD/CRD/Tokens на текущих экранах создают непонимание конечной стоимости. Влияние: UX цены, оформления, кошелька и платёжного сценария. **Не утверждает** автоматическое определение страны, точное место селектора, платёжного провайдера или готовность международных платежей.


- D-009 (07.11.2026, утверждено инициатором): **При первом входе страна по умолчанию — Беларусь; валюта интерфейса цен — BYN.** Обязательного экрана выбора страны перед знакомством с услугой не будет. Пользователь может явно сменить страну. Россия/RUB — только на будущем этапе выхода на рынок, не включать её как доступный способ оплаты без подтверждённой поддержки. Для любых других стран действуют те же ограничения. Размещение селектора и техническая реализация пока не утверждены.
- D-010 (07.11.2026, требование инициатора к отображению): Для Беларуси использовать **новый официальный графический знак белорусского рубля** (кириллическая «Б» с горизонтальной чертой), утверждённый постановлением Правления Нацбанка № 25 от 27.01.2026, действует с 04.02.2026. Текстовый международный код валюты — **BYN**, для России — **RUB** (знак ₽). Не заменять официальный знак нарисованной на глаз буквой «Б», латинской B или прежним Br: перед внедрением получить утверждённый оригинал/вектор и проверить корректность воспроизведения, права и техническую доступность. Пока символ недоступен — выводить BYN текстом; не выдавать суррогат за официальный знак. Источники: https://prg.kz/Document/?doc_id=32830894 и https://www.rrb.by/news/graficeskii-znak-oficialnoi-deneznoi-edinicy-respubliki-belarus-20260311-1304.

## [ГИПОТЕЗА] — ЕЩЁ НЕ УТВЕРЖДЕНО
- H-001: Основная визуальная тема светлая, почти монохромная, fashion-editorial / streetwear.
- H-002: Основная аудитория Беларуси — покупатели брендовой одежды на ресейле.
- H-003: Процент участника по product/design/growth: переговорная позиция 15–20%, база/срок/обязанности ещё не согласованы.
- H-004: Платные продажи возможны после проверки цены, законных платежей и воронки; не гарантированы.

- H-005: Непроверенная UX-деталь — лучше ли показывать селектор страны рядом с ценой, в профиле или на шаге оформления; автоматическая геолокация по IP, курсы конвертации, валюта фактического списания и доступность методов оплаты не утверждены.
