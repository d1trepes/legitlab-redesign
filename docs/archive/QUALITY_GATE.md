# Claude Code — критерии качества демо

Готовность заявлять только по выполненным пунктам. Не отмечать визуальную проверку, если не было браузерного preview.

## Главная и бренд
- [ ] Все восемь обязательных секций реализованы; ни одна не заменена заглушкой «coming soon» полностью.
- [ ] Есть явный H1 «Проверка подлинности брендовых вещей», ровно одна главная смысловая иерархия. Огромная LEGIT LAB декоративная.
- [ ] Selected C2 Compact используется без изменений полигонов; архив лого не затронут.
- [ ] Light использует black hoodie, dark — white hoodie из проверенных путей; нет нового AI-арта.
- [ ] Hero читается **без** анимаций; H1 и кнопки не перекрыты; предмет целиком (кроме края предплечья) не обрезается.
- [ ] Framed desktop navbar, active CTA, настройки темы доступны.
- [ ] Примеры появляются перекрывающей поверхностью после hero и ясно обозначены как demo, если нет разрешённых кейсов.
- [ ] Текст на русском; нет выдуманных экспертов, отзывов, цен, сроков, кейсов, лайфстайл-фото, гарантий.
- [ ] Цена обозначена как **BYN без выдуманной суммы**; нет настоящих платёжных сценариев.

## UX и маршруты
- [ ] «Начать проверку» из hero / navbar / pricing / footer ведёт в браузерный `/check`.
- [ ] `/check` работает в локальном demo режиме: категория, бренд, фото-preview, валидация, итоговый demo-state. Нет отправки файлов/денег/заказов.
- [ ] `/example-result` честно показывает **структуру возможного** результата, без вымышленного заключения.
- [ ] Внутренние ссылки существуют; недоступные функции ясно объяснены.
- [ ] Тема и mobile menu управляются мышью/клавиатурой, есть явный focus.
- [ ] Не выложен закрытый текст в исходник/DOM, нет секретов и токенов.

## Техническое
- [ ] `npm install` (или менеджер зависимостей) успешно.
- [ ] `npm run lint` и TypeScript-check успешно (если команда включена).
- [ ] `npm run build` успешно.
- [ ] Проверены 1440, 390 и промежуточная ширина. Нет горизонтального overflow.
- [ ] Проверены light/dark, отсутствие нечитаемого текста и контраст, системный reduced-motion.
- [ ] README содержит install/run/build и явно указывает «отдельная demo, не production».
- [ ] Оставлены notes: что временное, что подтверждено, какие лицензии и разрешения отсутствуют.
- [ ] Скриншоты desktop/mobile представлены **только если фактически сделаны**; не говорить, что визуал проверен, если нет инструмента.
- [ ] Никаких изменённых бинарных исходников `assets/`, никакого деплоя в production.

## Критерий визуального одобрения
Демо может считаться **технически готовым к показу**, но **не финально утверждённым дизайном**. После просмотра владельцем можно менять сетку, микротипографику, копирайт, адаптив и временные токены без переписывания продуктовых решений.
