## 2. TT Fonts: проверка [ВНЕШНЕЕ ИССЛЕДОВАНИЕ / ФАКТ О ПРАВИЛАХ]

**Официальные страницы**
- TT Firs Neue: https://typetype.ru/fonts/tt-firs-neue/
- TT Commons Pro: https://typetype.ru/fonts/tt-commons-pro/
- Лицензии: https://typetype.ru/licensing/
- Trial: https://typetype.ru/trial-fonts/

**[ФАКТ]** Шрифты коммерческие. Стартовая цена отдельного начертания на страницах указана «от 5 038,95 ₽» в исходной конфигурации; итог зависит от стиля, использования и выбранной лицензии, **не является итоговым счётом LEGIT LAB**. Большие семейства не покупать без нужды.

У TypeType различаются Desktop (графические макеты и органические публикации), Logo (публичный шрифтовой логотип), Webfont (живой текст на сайте), App (устанавливаемые приложения), Digital Ads, Video и другие способы использования. Webfont тарифицируется по ежемесячным просмотрам, по FAQ приобретение лицензии разовое в рамках лимита. Trial бесплатен только для внутренней оценки; **нельзя** выкладывать шрифт в публичную демоверсию или передавать font-файлы стороннему исполнителю.

**[УТОЧНИТЬ У ЛИЦЕНЗИАРА]**
1. Два адреса / веб-сайт и Telegram Mini App через WebView: достаточно ли конкретной Webfont-лицензии, если владельцем доменов будет белорусская сторона?
2. Векторизованный wordmark «LEGIT LAB» на TT Firs Neue: какую Logo-лицензию и на какое юрлицо оформлять?
3. Точные начертания (текущий тест — TT Firs Neue display + TT Commons Pro body), покупка, коммерческая доступность для белорусского лицензиата, права подрядчиков и публикация демоверсии.
4. Если будут платные рекламные креативы/ролики, получить отдельные условия Digital Ads/Video. Не смешивать это с этапом 05.

**[ВЫВОД]** Пара остаётся рабочей, но пока **не одобрена к публичному внедрению**. Данные о купленных лицензиях отсутствуют. Нельзя заливать файлы в публичный GitHub или отдавать пользователям.

Запрос с загрузкой PNG знака в визуальный поиск WIPO, проверка реестров Беларуси, международных обозначений и слов «LEGIT LAB» не выполнены; WIPO запрещает автоматизированные запросы. Без этого нельзя утверждать, что логотип свободен или зарегистрируем. Желателен поиск специалистом по relevant товарам/услугам до публичного применения.

### Матрица изображений на главной (не генерация ради заполнения)

| Секция | Что нужно | Решение по генерации |
|---|---|---|
| Header | logo + wordmark | фотографии не нужны |
| Hero | black/light и white/dark hoodies из `assets/hero/` | **новые не генерировать** |
| Примеры проверок | минимум 2–3 **разрешённых реальных кейса**: общий план + проверяемая деталь + допустимый вывод | не генерировать фальшивые доказательства, не публиковать приватные комментарии |
| Как мы проверяем | 1–2 разрешённые macro/detail фото бирок, швов, ткани или подтверждённый процесс | съёмка / права; генеративный conceptual арт только отдельно с честной маркировкой |
| Стоимость | текстовая иерархия и ясная BYN-цена после подтверждения | фото не нужны |
| SEO / статьи | 2–3 обложки, желательно реальные снимки/законно доступные кропы; статьи настоящие или явно демо | можно позже при контентном плане |
| Final CTA | чёткий оффер / чистая типографика, возможно существующий кроп | новая картинка не обязательна |
| Footer | навигация, юридические и контактные сведения | фото не нужны |

### Референсы, которые действительно помогут
1. Текстовый SEO-материал: длинная типографика на светлом/тёмном.
2. Доказательный кейс: большой предметный снимок + detail macro + ясно оформленный результат.
3. Компактная функциональная часть: стоимость и реальные состояния (disabled/loading/focus), без микротипографики.
4. 390 px кадр с logo/header/hero, чтобы проверить читаемость композиции.
