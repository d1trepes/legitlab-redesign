# ROADMAP — 8 последовательных этапов
Приоритет — цельная качественная демоверсия к созвону, без обещаний полного production за неделю.

| № | Этап | Что делаем | Критерий перехода |
|---|---|---|---|
| 01 | UX-аудит | Все существующие экраны и сценарии, issue log, сегменты B2C, IA, структура сайта | Знаем, что исправляем и почему |
| 02 | Референсы / айдентика | Анализ референсов, шрифты, сетка, фотостиль, светлая палитра, 2–3 SVG-логотипа | Пользователь утвердил направление; альтернативы сохранены |
| 03 | Desktop | Цельная главная в коде: header, hero, реальные проверки, как проверяем, цена, SEO-статьи, CTA, footer | Работает desktop, соответствует утверждённому стилю |
| 04 | Mobile / App | Адаптив и отдельный анализ Telegram-бота/Mini App, шаги заказа, статус, результат | На mobile ясно и читаемо, сценарии проверены |
| 05 | Social branding | TikTok, Instagram, Threads, Telegram, YouTube: аватары, обложки, карточки, короткие motion-системы | Единый узнаваемый стиль |
| 06 | B2C growth | Беларусь, потом Россия, каналы/UTM, KPI/CRM, тестовая цена, платежи, экономика | Гипотезы отделены от фактов, есть ответственные |
| 07 | Pitch | Проблема → доказательство → решение → demo → гипотезы/результаты → план → предложение | Понятный рассказ на созвоне |
| 08 | Terms | Роли, база расчёта 15–20%, отчётность, права, срок | Есть письменная ясность до масштабной неоплаченной работы |

## Правила качества
- Сначала факты → аудит → решение → критерий готовности → задача Codex.
- Не начинать код до выбора референсов.
- Референс разбирать через конкретные приёмы, не копировать.
- Варианты логотипа не удалять.
- Проверять desktop 1440 / mobile 390, CTA, доступность и обоснованность текста.
- Если времени мало: сократить объём второстепенных демонстраций, а не жертвовать понятностью.
