# Implementation notes — демо главной (08.11.2026)

Временные технические решения первой сборки. История решений — в `DECISIONS.md` (D-031—D-039).

## Стек
- Next.js 16 (App Router) + TypeScript, статический экспорт (`output: "export"`, папка `out/`). Серверного кода нет.
- Стили: CSS Modules на компонент + `app/globals.css` с токенами. Tailwind не используется.
- Шрифты: `@fontsource-variable/sofia-sans-extra-condensed`, `@fontsource-variable/golos-text` (OFL, кириллица), self-hosted.

## Темы
- `data-theme` на `<html>`; светлая по умолчанию. Выбор в «Настройках» (шестерёнка) сохраняется в `localStorage` (`ll-theme`). Системная тема выбор не переопределяет.
- Hero: светлая — `hero-black`, тёмная — `hero-white` (производные WebP из `assets/hero/*.png`, оригиналы не тронуты). Без CSS-инверсии.

## Изображения
- `public/img/*.webp` — сжатые копии файлов из `assets/hero/` и `assets/sections/` (по 2 размера: 640 и исходный).
- Фото каталога и обложки статей **не копируются**: подгружаются с `https://legit-lab.com/_next/image?...` по ключам из `lib/data.ts`. Если сайт не отвечает, показывается знак C2 на сером фоне. Для продакшна заменить на собственное хранилище/API.
- Генерированные фото (мужчина в куртке, категории, сцены «Как мы проверяем») — иллюстрации, а не фото реальных проверок.

## Данные (`lib/data.ts`)
- 8 карточек каталога (4 «Оригинал», 4 «Реплика»), цены 50/70 кредитов по брендам, пакеты кредитов, 3 статьи — прочитаны с публичных страниц legit-lab.com 08.11.2026.
- Цены пакетов в BYN не известны — выводится «Цена в BYN уточняется».

## Анимация
- Hero: появление букв и худи, бесконечное покачивание вокруг точки хвата, параллакс по курсору (только на устройствах с мышью) и подъём при скролле — через CSS-переменные `--px/--py/--sy`.
- Появление блоков при скролле (`data-reveal`). При `prefers-reduced-motion` всё статично.

## Что демо, а что нет
- «Начать проверку», «Войти», «Открыть кошелёк», карточки категорий → демо-окно со ссылками на legit-lab.com и Telegram-бота. Заявка не создаётся, данные не отправляются.
- Карточка каталога → окно с увеличенным фото и вердиктом, ссылка на историю на legit-lab.com.
- Статьи и соцсети — настоящие внешние ссылки.
- Индексация закрыта (`robots: noindex`).

## Проверено
- `npm run typecheck`, `npm run lint`, `npm run build` — без ошибок.
- Скриншоты 1440 и 390 в обеих темах (headless Chrome), горизонтального скролла нет. В песочнице сборки legit-lab.com недоступен, поэтому на скриншотах фото каталога и статей заменены знаком; в обычном браузере они загружаются.
