# Legit Lab — контекст и рамки
Актуализировано: 2026-11-07. Факты основаны на рассказе инициатора и скриншотах; непроверенные числа отмечены.

## Что есть [ФАКТ СО СЛОВ КОМАНДЫ]
- Legit Lab / legit-lab.com — B2C проверка оригинальности по фотографиям.
- Есть публичный сайт, веб-приложение, Telegram-бот/канал, TikTok.
- Около четырёх месяцев разработки и примерно 300 бесплатных пользователей / обращений — **уточнить определение и точное число**.
- Платная экономика пока не доказана; фактические продажи нужно проверить.
- Есть эксперт по проверкам и техническая команда; дизайн/product/growth участник обсуждает вход в проект.

## Зафиксированные рамки
- Сначала только B2C, без B2B и партнёрских программ.
- География: сначала Беларусь; Россия и СНГ позже, после проверки платного спроса.
- Название и домен сохраняем.
- Работа без Figma: ChatGPT Project — штаб, Codex — исполнитель, GitHub — код и спецификации.
- Поэтапная работа: UX-аудит → референсы и айдентика → desktop → mobile/app → social → growth → презентация → условия.

## Визуальная гипотеза, НЕ РЕШЕНИЕ
Светлый минималистичный fashion-editorial / streetwear; почти монохром; крупный выразительный гротеск; настоящие предметные фото. Бирюзовое свечение исключить. Точные шрифты, сетку, фотостиль и логотип ещё не выбрали.

## Главная
Header → Hero → Реальные проверки (оригинал/реплика) → Как проверяем → Стоимость → SEO-статьи → Final CTA → Footer.

## Что проверить на UX-аудите
- Все экраны гостевого/авторизованного режима, заказ, фото, категории, кредитная система CRD, оплата, история, статус и результат.
- Действительный путь из Telegram-бота и Mini App; не смешивать эти продукты без проверки.
- Язык интерфейса, читаемость, ясность оффера, авторизация, возражения перед оплатой.
- Права на фото кейсов и их обезличивание; не использовать публично лица несовершеннолетних без необходимых разрешений.

## Дополнение по UX-аудиту — 07.11.2026
[ФАКТ — по скриншотам] На `legit-lab.com` есть не только информационная главная, но и веб-интерфейс: Home, New Request, Wallet, Orders, Profile, статьи и публичные отчёты. Сценарий заявки показан до шага 03/04.
[ФАКТ — по скриншотам] Telegram-бот `@legit_lab_bot` по `/start` показывает приветствие и кнопку «Открыть приложение», ведущую в Telegram Mini App. Канал содержит обучающие публикации и кейсы.
[ФАКТ — наблюдение инициатора] Непонятны полный путь проверки, роль эксперта и смысл фотографий в публичных карточках; мелкие и блеклые подписи затрудняют чтение. Стоимость в CRD/Tokens/USD воспринимается как барьер в контексте Беларуси.
[ГИПОТЕЗА] Чёткие объяснения процесса, вердикта и цены одной проверки, возможно с отображением BYN для целевой аудитории, улучшат понимание оффера. Конверсионный эффект не измерен.
[УТОЧНИТЬ] Web↔Mini App: единые ли авторизация, история и баланс; шаг 04/04; работающая оплата; сроки и состав заключения; права на публичные изображения.
[РЕШЕНИЕ] Продолжаем этап 01; не передаём задачи на визуал или код до утверждения аудита, IA и референсов.

## Принцип отображения стоимости (решение 07.11.2026)
[РЕШЕНИЕ] Для B2C нужна локализация цены по стране пользователя с возможностью выбрать страну: первый рынок Беларусь — BYN, Россия — RUB после отдельного решения о расширении; дополнительные страны и валюты — только после подтверждения поддержки. Источник — прямое требование инициатора, не проверенный платёжный функционал.
[РЕШЕНИЕ] На первом входе по умолчанию Беларусь / BYN, без обязательного выбора страны перед знакомством с услугой. Возможность изменить страну сохраняется. Россия/RUB — будущий рынок, не активировать неподдерживаемые платежи.
[РЕШЕНИЕ — отображение] Для белорусской цены предусмотреть новый официальный символ белорусского рубля (кириллическая «Б» с горизонтальной чертой), установленный Нацбанком в 2026 году. Текстовый код BYN остаётся основным гарантированно читаемым обозначением, RUB — для России; готовый официальный вектор/ассет получить и проверить отдельно, не рисовать приближение.
[ГИПОТЕЗА] Размещение выбора страны рядом с ценой или при оформлении; способ определения страны автоматически пока не утверждён.
[УТОЧНИТЬ] Отображаемая vs фактическая валюта списания, CRD/Tokens, курсы, комиссия, способы оплаты, требования местного законодательства. Нельзя обещать запуск платежей в BYN/RUB или остальных валютах без подтверждения.


## Бизнес-гипотезы, НЕ ФАКТ
- Возможный первый B2C-сегмент: покупатели брендового streetwear на ресейле в Беларуси.
- 15–20% с продаж — только начальная переговорная гипотеза, не договорённость.
- Первые оплаченные заказы возможны после законной организации платежей, подтверждения цены и работающей воронки; не гарантированы.

## Запрещённые обещания
Нет 100%-ной гарантии подлинности по фото, гарантированных продаж, подтверждённой юридической пригодности ИП или конкретной выручки без проверки.
