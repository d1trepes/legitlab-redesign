# LEGIT LAB — типографика и mini-brand system v1 (предложение на утверждение)

**08.11.2026 · Этап 02 / НЕ этап 03.** Дизайн-параметры ниже имеют статус **[ГИПОТЕЗА]**, пока инициатор не посмотрел реальные пробы на 1440/390 и две темы. Это не рабочий UI-код, не разрешение Codex начать разработку и не факт покупки коммерческих шрифтов.

## A. Что уже утверждено [РЕШЕНИЕ / ФАКТ]
- Название LEGIT LAB, `legit-lab.com`, B2C Беларусь / BYN, интерфейс на русском.
- Основной графический символ: **C2 Compact** (D-029), исходные полигоны + нормализованный SVG-холст в `assets/logo/selected/C2-compact-selected.svg`. Это **дизайнерский выбор**, а не юридическая чистота товарного знака.
- Монохром, **light default**, полноценная dark через «Настройки», без цветного рекламного акцента и cyber-glow.
- Hero: композиционный большой LEGIT LAB **не H1**; чёрное худи в light и белое в dark из `assets/hero/`; H1 «Проверка подлинности брендовых вещей», пояснение и отдельные CTA снизу слева.
- Desktop framed navbar и переход следующего блока с перекрывающей скруглённой поверхностью. Полные 8 секций не менять.
- TT Firs Neue + TT Commons Pro — ранее выбранная **пара для теста**, не разрешённые к использованию файлы.

## B. Голос визуальной системы [ГИПОТЕЗА]
`editorial fashion × streetwear × authentication`: **крупный характер в брендовых и заголовочных зонах, максимальная ясность везде, где пользователь совершает действие**. Избегать «люксовой» мелкости 10–12 px, чрезмерных капсульных кнопок, множества надзаголовков, псевдоподтверждений, свечения и декора без функции.

## D. Графический знак + надпись [ГИПОТЕЗА пропорций]
- Отдельный C2 слева; wordmark LEGIT LAB справа; знак **не** LL-монограмма и не часть букв.
- Desktop framed navbar: **32×32** знак, зазор **12 px**, wordmark **22 px**, собранная высота lockup примерно 36–40 px.
- Mobile: знак **28×28**, зазор **10 px**, wordmark **19 px**. Проверить, что слово не вытесняет действия.
- Avatar: только C2 48/64 px; favicon 16/32; не вставлять wordmark в 16 px.
- Полностью монохромная инверсия знака по теме, без градиентов, контурных теней и отдельных декоративных деталей.
- Если TT Firs Neue в наборе LEGIT LAB даёт слабую оптику, корректировать **треккинг и интервалы**, а не менять утверждённый знак. Векторный wordmark позже и только после лицензии/проверки.

## E. Два набора цветовых токенов [ГИПОТЕЗА]

| Токен | Light (default) | Dark | Назначение |
| --- | --- | --- | --- |
| canvas | `#F5F4F1` | `#111111` | основная поверхность |
| surface | `#FFFFFF` | `#1B1B1B` | карточки, framed navbar |
| text-primary | `#121212` | `#F5F4F1` | основные заголовки, body |
| text-secondary | `#575754` | `#B9B8B4` | вторичный читабельный текст |
| divider | `#D3D1CC` | `#414141` | декоративные делители, не единственный сигнал поля |
| control-border | `#8B8984` | `#777777` | границы интерактивных контролов |
| surface-muted | `#ECEAE5` | `#262626` | тихая вторичная поверхность |

**Проверено расчётом контраста WCAG:** primary/canvas light **17.03:1**, secondary/canvas light **6.59:1**, primary/canvas dark **17.17:1**, secondary/canvas dark **9.51:1**; на surface primary/secondary также выше 4.5:1. Это **проверка этих конкретных сочетаний**, не автоматическая доступность всей страницы. Для текстовых элементов стандарт AA: не менее 4.5:1 обычный текст и 3:1 крупный (см. https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum).

**Взаимодействие:** primary CTA инверсия темы (light: `#121212` фон + `#FFFFFF` текст; dark: `#F5F4F1` фон + `#111111` текст). Secondary CTA — outline с читаемой обводкой; hover/focus/disabled требуют визуальной и текстовой проверки. Фокус видим по контуру 2–3 px и offset, не только цветом. Статус оценки «Оригинал / Вероятная реплика / Неопределённо» — только если подтверждена командой точная терминология; всегда текст, не одна цветовая точка.

## F. Сетка, интервалы, радиусы [ГИПОТЕЗА]
- Desktop контроль **1440 px**: max content **1344 px**, боковые поля **48 px**, **12 колонок**, gutter **24 px**; navbar framed внутри общего контейнера.
- Mobile контроль **390 px**: боковые поля **20 px**, контент **350 px**, **4 колонки**, gutter **12 px**. Проверка также 320, 360, 768, 1024, 1920.
- Отступы базовой системы: `4,8,12,16,24,32,48,64,96,128` px; внутри карточек 20–32, между секциями 96–128 desktop / 64–80 mobile.
- Button radius **8 px**, cards **12 px**, большие разделяющие поверхности **28–32 px** (только переход от hero, а не все карточки подряд).
- Фиксированные ширины допускаются только в разумных контейнерах; не создавать горизонтальный скролл.
- Точки взаимодействия минимум **44×44 CSS px** как более удобная рекомендация (строгое WCAG 2.2 AA 2.5.8 допускает 24×24 либо исключения по интервалам: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum).

## G. Поведение элементов [ГИПОТЕЗА]
1. **Framed navbar**: логотип / центральные основные пункты / сервисные действия / CTA без hamburger на desktop; «Кошелёк» для гостя и точные URL отдельно уточнить. На 390 px необходим другой layout навигации, НЕ обещать ту же плотность.
2. **Primary CTA**: минимальная высота 48–52, прямоугольник 8 px; название «Начать проверку». Ведёт на Web-заявку из сайта; бот в Mini App, без принудительного перенаправления.
3. **Secondary**: тонкая обводка или текстовая ссылка, контрастная и с фокусом. «Как это работает» прокручивает к секции «Как мы проверяем».
4. **Карточка проверки**: большое фото, бренд/категория, дата/вердикт только когда подтверждены права и данные; никакой фальшивой экспертной оценки.
5. **Карточка статьи**: одна обложка, категория, заголовок, короткая аннотация, видимая ссылка; реальные материалы или заметная пометка демо.
6. **Цена**: BYN текстом при отсутствии проверенного вектора нового знака; число не выдумывать и не показывать «от ...» без доказательств. Один понятный основной тариф вместо демонстрационной мешанины CRD.
7. **Состояния**: hover, active, focus, disabled, loading, empty, error; без фиктивных success/reviews/trust badges.

## H. Фотостиль / motion [ГИПОТЕЗА]
- **Hero**: использовать только текущие рабочие PNG/WebP из `assets/hero/`, ни одного перегенерированного худи; `object-fit: contain`, сохранение анатомии и бирок.
- **Real checks**: реальные разрешённые фото (общий план + детали), без личных сообщений и скрытой экспертной переписки. Если прав нет — честная демонстрационная заглушка, не «кейс».
- **How we check**: реальная съёмка бирок/швов/фактуры без раскрытия закрытого экспертного процесса.
- **SEO**: предметные фотографии с законным источником; 2–3 содержательные статьи, не декоративный фотокаталог.
- **Motion**: статическая сцена должна быть полноценна. Допустимо мягкое однократное появление hero при первом экране (~300–500 ms) без блокирования CTA, дальше тихие hover/focus; обязательно `prefers-reduced-motion` и статичный fallback. Не считать 3D частью этого этапа.
