# LEGIT LAB — редизайн (демо)

Подготовленные материалы для сборки многостраничной демоверсии сервиса проверки подлинности брендовых вещей.

- [BRIEF.md](BRIEF.md) — бриф: задача, продукт, страницы, правила.
- `references/` — референсы, скриншоты текущего legit-lab.com, отклонённая v1.
- `assets/` — логотип, hero-худи, предметные фото.
- `content/` — каталог реальных проверок с фото, цены, статьи, ссылки.
- `docs/archive/` — документы прошлых этапов.

Кода сайта в `main` пока нет. Прошлая отклонённая версия лежит в ветке `demo/site-v1`.
