# LEGIT LAB — Redesign Demo

Отдельный приватный репозиторий для концептуального редизайна B2C-сервиса Legit Lab. Production-сайт не затрагиваем.

## Как работаем
- **ChatGPT Project**: обсуждаем продукт, аудит, дизайн, стратегию и утверждаем решения.
- **GitHub**: храним согласованные спецификации, референсы и исходный код.
- **Codex**: читает `AGENTS.md` и документы в `docs/`, реализует только одобренные задачи.

## Сейчас
**Этап 01 — UX-аудит.** Визуальное направление и логотип пока не утверждены. Не генерировать и не кодировать главную страницу до выбора референсов и фиксации решения.

## Основные документы
- `AGENTS.md` — правила для Codex
- `docs/PROJECT_BRIEF.md` — что известно о продукте
- `docs/ROADMAP.md` — этапы и критерии готовности
- `docs/DECISIONS.md` — утвержденные решения и гипотезы
- `docs/REFERENCE_NOTES.md` — анализ референсов

- `docs/UX_AUDIT.md` — рабочий аудит текущих экранов, UX-рисков и неизвестных вопросов (этап 01)
- `docs/CURRENT_SITEMAP.md` — текущая карта сайта, Telegram-бота и Mini App (этап 01)

**Статус аудита:** черновик для совместного согласования, не команда на редизайн и не спецификация для Codex.

- `docs/PROPOSED_SITEMAP.md` — черновик будущей IA на русском; сайт и Telegram Mini App имеют собственные пути подачи заявки.

**Решения этапа 01:** интерфейс на русском, сайт ведёт в оформление на сайте, Telegram Mini App — в оформление внутри Telegram; блок об экспертизе называется «Как мы проверяем». Английская локализация — возможное будущее расширение, не текущая задача.

- `docs/EXPERT_WORKFLOW_NOTES.md` — сведения об экспертной обработке из README production и переписки, с границами подтверждения.
- `docs/REFERENCE_NOTES.md` — добавлен LegitApp как отдельный референс; тёмная и светлая темы пока **гипотезы**, визуальное направление не выбрано.

Оригинал: https://legit-lab.com/ (не изменять без отдельного согласования).
