# site/

Код главной страницы LEGIT LAB. Всё, что лежит в этой папке, публикуется на https://d1trepes.github.io/legitlab-redesign/

- `index.html` — разметка: шапка, 6 блоков, футер. Заголовок и кнопки первого экрана видны без JS.
- `styles.css` — система C «Студия» (`decisions/20-visual-system.md`).
- `main.js` — облако из 7 кадров, iPhone, фильтр проверок, появление блоков, окно «Страница в разработке». Данные — из `content/catalog.json`, `articles.json`, `links.json` по raw-ссылкам (есть запасные данные).

Фото — WebP-копии в `site/img/` (делает `tools/optimize-images.py`), мобильные размеры подключены через `<picture>` с `media="(max-width:1023px)"`. Без сборщиков. Эталон — `decisions/25-prototype.html`.

## Мобильная версия (чат 4)

- Все мобильные стили — в `@media (max-width:1023px)` (телефон — `max-width:767px`), десктоп от 1024 px не меняется.
- В `main.js` мобильная логика включается через `matchMedia`; десктопный цикл облака на мобилке не крутится.
- Облегчённый режим (класс `lite`): «уменьшить движение», экономия трафика, ≤ 4 ядер или ≤ 3 ГБ памяти.
- Версию в `styles.css?v=…` и `main.js?v=…` менять при каждом изменении.
