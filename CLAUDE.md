# CLAUDE.md

LEGIT LAB — демоверсия редизайна сервиса проверки подлинности брендовых вещей. Не production.

**Главный документ: [BRIEF.md](BRIEF.md).** Прочитай его целиком перед работой. Он важнее всего в `docs/archive/`.

Порядок:
1. `BRIEF.md` — задача, продукт, что не так с прошлой версией, карта страниц, правила.
2. `references/README.md` + все изображения в `references/` — референсы и текущий сайт.
3. `assets/` — логотип (`logo/selected/`), hero-худи (`hero/`), предметные фото (`sections/`).
4. `content/` — реальные данные: каталог проверок с фото, цены, статьи, ссылки.
5. `docs/archive/` — история прошлых этапов. Читать только при необходимости.

Язык интерфейса — русский. Работать в отдельной ветке, итог — Pull Request в `main`.
