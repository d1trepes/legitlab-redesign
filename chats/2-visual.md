# Чат 2 — фото, шрифты, цвета и рабочий прототип

**Результат чата:** список новых фото с готовыми промптами для генерации, дизайн-система (шрифты, цвета, кнопки, логотип) и **полностью заполненный рабочий прототип главной для десктопа** — как кликабельный макет в Figma, только в браузере: настоящие фото, настоящие тексты, весь интерактив работает. По нему чат 3 соберёт сайт.
**Файлы итога:** `decisions/20-visual-system.md`, `decisions/22-photos.md`, `decisions/25-build-prompt.md`, прототип `decisions/25-prototype.html`

Концепция и структура уже выбраны — `decisions/10-concept.md` и вайрфрейм `decisions/10-concept-wireframe.html`. Не меняй их без моего слова. **Только десктоп** (1280–1440); мобильную версию сейчас не делаем.

## Задание

1. **Прочитай** `BRIEF.md`, `references/README.md`, `decisions/10-concept.md`, открой вайрфрейм. Посмотри фото в `assets/v2/`, `content/catalog-photos/`, `content/article-covers/`.

2. **Фото.** Пройди по каждому блоку вайрфрейма и составь список:
   - какие существующие фото подходят и куда (имя файла → блок → кадрирование);
   - какие фото нужно сделать заново. Как минимум: вещь для первого экрана с вырезанным фоном; 7 крупных кадров деталей **той же** вещи (общий вид, бирка, этикетка, швы, фурнитура, логотип, изнанка); человек в объёмной одежде в полный рост для финала, на ровном фоне под вырезку; более широкие версии категорий для двух больших плиток, если 4:5 не подходит; всё, что ещё понадобится;
   - для каждого нового фото: имя файла (`assets/v3/<имя>.png`), где стоит, пропорции и размер в пикселях, нужен ли прозрачный фон, и **готовый промпт для генерации** на английском — в стиле существующей серии: монохром, студийный серый свет, объёмная одежда, fashion-editorial, без логотипов реальных брендов, без текста на бирках;
   - экраны мини-приложения для iPhone в блоке «Как это работает»: что на каждом из трёх экранов, рисуем их кодом или нужны картинки.
   Покажи список артефактом: таблица со ссылками на текущие фото и промптами, которые можно скопировать.

3. **Варианты системы.** Предложи 3 варианта. В каждом:
   - пара шрифтов с открытой лицензией и кириллицей: акцентный для заголовков разделов и брендов в лентах и текстовый для всего остального. Один вариант — с Alumni Sans как акцентным. Запрещённые шрифты — в `BRIEF.md`;
   - монохромная палитра с HEX: фон, поверхности, текст, второстепенный текст, линии, тёмные листы. Акцентный цвет — только если нужен, один и с объяснением;
   - шкала размеров текста и правило, где допустим акцентный шрифт (не больше одного заголовка на экран);
   - кнопки: заливка и обводка, наведение, нажатие, скругление;
   - логотип: знак C2 + надпись LEGIT LAB под знаком по центру или рядом, выровненная по центру знака.

4. **Образцы.** Покажи все 3 варианта в одном артефакте с переключателем — настоящими кусками нашей главной: шапка, лист первого экрана с заголовком, плитка категории на чёрном листе, две проверки с итогом «Оригинал» и «Реплика», кусок футера. Шрифты подключи по-настоящему, фото — по raw-ссылкам из GitHub.

5. **Прототип главной.** После выбора системы собери всю главную на выбранной системе:
   - все блоки и футер ровно по `decisions/10-concept.md`, в одной 12-колоночной сетке;
   - настоящие тексты, настоящие фото по raw-ссылкам; где нового фото ещё нет — аккуратная заглушка с именем будущего файла из списка фото;
   - **весь интерактив работает:** облако из 7 кадров в 3D вращается за мышью и собирается в ленту при прокрутке; наведение на категории с кнопкой «Проверить»; закреплённый блок с iPhone, экраны которого листаются при прокрутке; фильтры проверок; «уменьшить движение»;
   - публикуй артефактом и правь по моим комментариям, пока я не согласую. Когда я загружу новые фото в `assets/v3/`, подставь их.

6. **Итог.** Когда я напишу «Итог»:
   - `decisions/20-visual-system.md` — дизайн-система: шрифты с начертаниями и ссылками, цвета с HEX, шкала размеров, сетка, кнопки, отступы, скругления, правила «можно / нельзя»;
   - `decisions/22-photos.md` — финальный список фото: файл → блок → кадрирование, какие ещё не сделаны, промпты;
   - `decisions/25-prototype.html` — согласованный прототип одним файлом;
   - `decisions/25-build-prompt.md` — подробный промпт для чата 3: блок за блоком, что где стоит, какие фото и тексты, как работает интерактив (с параметрами анимаций), какие кнопки куда ведут. Чат 3 должен собрать страницу только по нему и прототипу, ничего не придумывая.
