# Чат 2 — шрифты, цвета и макет

**Результат чата:** дизайн-система (шрифты, цвета, кнопки, логотип) и визуальный макет всей главной на настоящих фото. В конце — готовый промпт для сборки в чате 3.
**Файлы итога:** `decisions/20-visual-system.md` и `decisions/25-build-prompt.md`

Концепция и структура уже выбраны — `decisions/10-concept.md`. Не меняй их без моего слова.

## Задание

1. **Варианты системы.** Предложи 3 варианта. В каждом:
   - пара шрифтов с открытой лицензией и кириллицей: акцентный для редких крупных заголовков и текстовый для всего остального. Один вариант — с Alumni Sans как акцентным. Запрещённые шрифты — в `BRIEF.md`;
   - монохромная палитра с HEX: фон, поверхности, текст, второстепенный текст, линии, тёмные блоки. Акцентный цвет — только если нужен, один и с объяснением;
   - шкала размеров текста и правило, где допустим акцентный шрифт (не больше одного заголовка на экран);
   - кнопки: заливка и обводка, наведение, нажатие, скругление;
   - логотип: знак C2 + надпись LEGIT LAB под знаком по центру или рядом, выровненная по центру знака.

2. **Образцы.** Покажи все 3 варианта в одном артефакте с переключателем. Не таблицей шрифтов, а настоящими кусками нашей главной: шапка с логотипом и кнопками, первый экран с заголовком, две карточки настоящих проверок с итогом «Оригинал» и «Реплика», абзац текста, кусок футера. Шрифты подключи по-настоящему, фото бери по raw-ссылкам из GitHub.

3. **Макет главной.** После выбора системы собери визуальный макет всей главной на выбранной системе и настоящих фото. Можно без сложного интерактива: важно, как страница выглядит. Правим макет по моим комментариям, пока я не согласую.

4. **Промпт для сборки.** Когда я напишу «Итог»:
   - собери `decisions/20-visual-system.md` — дизайн-система: шрифты с начертаниями, цвета с HEX, шкала размеров, кнопки, отступы, правила «можно / нельзя»;
   - напиши `decisions/25-build-prompt.md` — подробный промпт для чата 3: блок за блоком, что где стоит, какие фото и тексты, как работает интерактив, какие кнопки куда ведут. Чат 3 должен собрать страницу только по нему, ничего не придумывая.
